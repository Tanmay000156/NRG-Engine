NRG Engine integrates 10 compilers: C (GCC 13), C++ (Clang), Python 3.12, Rust, Go, Java 21, JavaScript (Node/Browser), TypeScript, C#, and PHP. All compilation runs through sandboxed Judge0 CE architecture.

Universal Graphics Workspace

Access vector turtle drawings, Python Matplotlib plots, and Java AWT graphics via the Graphics tab in the terminal docking panel.
