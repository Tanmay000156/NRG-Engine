Help & Developer Support

Polyglot Compiler Engines

NRG Engine integrates 10 compilers: C (GCC 14), C++ (GCC 14), Python 3.12 (with Pyodide WASM fallback for Matplotlib/NumPy/Pandas), JavaScript (Node.js 22), Java 17, Rust 1.85, Go 1.23, C# (Mono/.NET), PHP 8.3, and Kotlin 2.1. Local execution uses isolated child sandboxes with 10s compile and 30s runtime limits; cloud execution routes seamlessly through Judge0 CE and Pyodide WebAssembly.

Universal Graphics Workspace

Access vector turtle drawings, Python Matplotlib plots, and Java AWT graphics via the Graphics tab in the terminal docking panel.

Execution Diagnostics

Compiler errors, warnings, and memory stack traces are highlighted in real-time in the Problems and Terminal docks.
